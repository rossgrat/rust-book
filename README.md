# Rust book exercises

Practice from [The Rust Programming Language](https://doc.rust-lang.org/book/):

- [hello-world](hello-world): standalone Rust program.
- [hello-cargo](hello-cargo): first Cargo project.
- [guessing-game](guessing-game): interactive guessing game.

Run a Cargo project from its own directory:

```sh
cd guessing-game
cargo run --locked
```

The manifests use Rust edition 2024. Keep exercise implementations, lockfiles, and sample inputs with their projects.
